# FlowB2B v2 - Sistema de Gestão B2B

Sistema completo de gestão de compras e vendas B2B com integração Bling.

## Stack
- Next.js 16.1
- TypeScript
- Tailwind CSS
- Supabase
- Row Level Security (RLS)

## Deploy
- Render.com
- CI/CD com GitHub Actions

## Segurança
✅ RLS implementado
✅ Autenticação JWT
✅ Multi-tenant isolation
